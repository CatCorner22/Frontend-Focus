**What this is.** Four data files with 76 records. Each record states one finding, how strong the evidence is, how a program could check a design against it, and what remains unverified. The owner asked for this research on 2026-11-14 (decision D52).

**Who wrote it, and how far to trust it.** Four AI assistants wrote the records, one research task each. Nobody has reviewed them. The session's network blocked most research sites, so nearly every study was seen only as a search engine's summary; the count for each file is in its table below. **What the Studio uses of it.** Five research rules (`packages/core/src/catalog/researchRules.ts`), three Directions and one Skin (the Japanese-design file), and the source lines of the six Overlays. Everything else is reference material for later milestones.

**What can go wrong with this file.** It is generated from the data files; if a data file changes, this page falls behind. The data files are the authority.
